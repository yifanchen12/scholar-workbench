## 答案与过程

### 练习1：跨边界的四角

四角中B=0、D=0恒定；A和C在组内变化，因此消去A和C。

# 卡诺图化简

变量顺序：ABCD（左侧为高位）

F = Σm(0, 2, 8, 10)

| AB \ CD | 00 | 01 | 11 | 10 |
|---|---:|---:|---:|---:|
| 00 | 1① | 0 | 0 | 1① |
| 01 | 0 | 0 | 0 | 0 |
| 11 | 0 | 0 | 0 | 0 |
| 10 | 1① | 0 | 0 | 1① |

## 分组

①：(m0, m2, m8, m10) → B'·D'

## 最简与或式

F = B'·D'

$$F = \overline{B}\overline{D}$$

真值验证：通过（无关项不参与一致性要求）。
优化顺序：先最少乘积项，再最少文字数；等价最简式可能不唯一。
编号标记表示分组，重复标记表示该格参与多个组。

分组图：[SVG](../examples/kmap-corners.svg)

### 练习2：同一格可以重复使用

其中AC、BC各为一个四格组；m5与m7形成一组，得到A'BD。m7、m14、m15等可参与不止一个组。

# 卡诺图化简

变量顺序：ABCD（左侧为高位）

## 分组

①：(m6, m7, m14, m15) → B·C
②：(m5, m7) → A'·B·D
③：(m10, m11, m14, m15) → A·C

## 最简与或式

F = B·C + A'·B·D + A·C

$$F = BC+\overline{A}BD+AC$$

真值验证：通过（无关项不参与一致性要求）。
优化顺序：先最少乘积项，再最少文字数；等价最简式可能不唯一。
编号标记表示分组，重复标记表示该格参与多个组。

## 线性回归第一步

默认数据：(-2,-3)，(-1,-0.8)，(0,1)，(1,3.1)，(2,4.8)，(3,7.2)

模型ŷ=wx+b，L=Σ(ŷ−y)²/(2m)，w=b=0，η=0.1。
初始L=7.927499999999999；dw=-6.8500000000000005；db=-2.0500000000000003。
同步更新后w=0.685，b=0.20500000000000004，L=3.6491645833333326。
最小二乘参考w=1.9971428571428573，b=1.0514285714285716，L=0.009571428571428583。

## 三个实验

1. η从0.1改为0.8，先预测，再看1步和20步的损失。
2. x放大50倍，说明斜率和稳定学习率为什么改变。
3. 加入离群点，比较训练最优与测试MSE。

## 易错点

- 卡诺图的首尾相邻；同一个1可以参与多个组。
- 无关项的输出没有强制要求，只有题目明确允许才能使用。
- 梯度必须从同一组旧参数计算。
- 测试数据不参与训练，也不应用作反复调参后的独立最终评估。
- 草稿字数口径要与申报系统一致；经历需保留证据。
