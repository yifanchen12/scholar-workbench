# 把现有课堂截图接入工作台

工作台接收明确的问答文本。课堂截图先在你常用的聊天中整理，核对后再导入；识别模糊或条件不全的题，不把猜测写成标准答案。

## 一次完整的小流程

1. 一次上传同一主题的少量课堂截图，并给出课程方向。你已有的`class-notes-review`技能可生成Markdown/PDF复习材料；也可使用下方提示词。
2. 先核对原题、变量、正负号与题目条件。数字逻辑的最小项与无关项分别核对，电路的参考方向明确。
3. 只复制问答文本代码块内的内容，到工作台“复习与错题 → 批量录入问答卡”。选择课程方向，先预览再加入。
4. 复习时先写或口述答案，再评分。计算题若只记得结果，就把“解释关键一步”另记成自己能回答的问题。

## 可复制到下一次截图整理聊天的提示词

```text
请根据我上传的课堂截图制作自学复习材料。我是北邮2025级人工智能专业学生。

先还原可辨认的题干、符号、已知条件与课堂知识点。模糊文字标“需确认”，不要补造题目条件、图中连线、无关项或标准答案。没有足够条件的问题列在待确认部分，不放入可导入卡片。

请提供：
1. 简明的知识点与推导，突出适用条件和最容易出错的一步。
2. 少量自测题及答案，先题后答。
3. 最后一个独立text代码块，放不超过12张关键问答卡，用于邮研工作台批量录入。

问答格式必须是：
问：一个能独立回答的问题
答：关键步骤、适用条件与易错点
---
问：下一张卡的问题
答：下一张卡的答案

每张只有一个以“问：”开头的行、一个以“答：”开头的行。答案可多行，但后续行不要再次以“问：/答：”开头，也不要包含独立的“---”分隔行。代码块内不加标题、编号或额外说明；问题不超过1000、答案不超过4000个浏览器字符串字符。不要把同一结论拆成许多重复卡。

优先选能检验理解的问题：为什么这一步成立、哪些条件缺一不可、换一个输入会怎样、怎么独立检查答案。遇到我无法从截图独立确认的内容，明确留下待确认项。
```

## 计算题怎样核对

| 场景 | 核对动作 |
|---|---|
| 卡诺图 | 将确认过的最小项与无关项输入逻辑实验室；先自己圈组，再检查覆盖；对照真值表与成本，不只比较公式文字 |
| 电路 | 保留原参考方向；核对KCL/KVL符号与独立/受控源；本工作台的知识卡不承担任意电路求解 |
| 回归 | 先核对损失是否含1/2、是否取平均；同一份旧参数求梯度；再看更新与损失是否一致 |
| 分类 | 核对真实标签与类别编号、矩阵方向、预处理来源；区分训练、验证、测试与实际使用输入 |

答案“能解释”和答案“看起来熟悉”是两种不同状态。先用一两个代表题建立检查方法，再增加卡片数量。完全重复卡会跳过；同题不同答案会作为两张新卡保留，导入前应判断是否存在矛盾。
