# 算法与边界

## 卡诺图与精确覆盖

输入变量个数限定为2、3、4，A是最高位。最小项与无关项各去重、排序；集合重叠、非整数、越界或非法分隔输入立即报错，不隐式截断。

行列采用格雷码。四变量的行AB和列CD均为00、01、11、10；三变量行为A=0,1，列为BC的格雷码。

算法枚举每个变量为0、1、不限定（`-`）的所有立方体，最多3⁴=81个。只保留不覆盖任何0、且至少覆盖一个实际1的立方体，再剔除包含于更大有效立方体的项，得到质蕴涵项。

以尚未覆盖的最小项构成位掩码，递归选择一个未覆盖最小项并尝试包含它的质蕴涵项。每步严格减少剩余集合，缓存相同剩余集合的最优解。比较顺序是：

1. 乘积项个数更少；
2. 项数相同时，文字总数更少；
3. 同成本时，以模式字符串稳定选一个结果。

“最简”在这里明确指此成本顺序的最优与或式（SOP）。它不表示最少门数、最少延迟、最简异或式或全部等价最优式。若老师采用不同成本标准，需按题意检查。

空最小项取0，包括仅有无关项的输入。所有非无关输入均应为1时，可以得到常量1。无关项上的输出不强制一致。

每个结果重新遍历完整真值表。小规模与随机约束测试另外用“逐位固定掩码枚举 + 按已覆盖最小项集合动态规划”核对最优项数与文字数。完整枚举测试还使用另一种前向算法：所有基本立方体的完整真值掩码逐个OR，按递增掩码累计最小成本（100×项数+文字数）。OR严格增加非重复覆盖的数值掩码，形成无环图；每个函数都能由单格最小项表示。这个算法允许重叠，不依赖应用的质蕴涵项筛选与剩余覆盖递归。

全部65536个四变量布尔函数、全部6561个三变量0/1/无关项约束的功能与最优项数/文字数均已独立核对。三变量无关项通过枚举所有允许的完整函数取最小成本。四变量含无关项另有260组随机检查，未枚举全部3¹⁶种约束。

SVG组框对每个组的行、列连续段作笛卡尔积。跨边界的组拆成同色虚线段框，同一格的数字列出参与的所有组；不把四角错误画成包含中间0的完整大矩形。

参考概念可见 [MIT Computation Structures 逻辑结构讲义](https://ocw.mit.edu/courses/6-004-computation-structures-spring-2017/pages/c4/c4s1/)。本项目代码与演示题为独立实现。

## 表达式输入与自主圈组

表达式用递归下降解析成只含变量、常量、取反、与、异或、或的树，不使用eval。支持AB的隐式与、`·`/`*`/`&`、`+`/`|`、`^`/`⊕`、前置`!`/`~`、后置`'`/`′`以及括号。优先级从高到低为取反、与、异或、或；可以用括号明确不同约定。最多256个非空白字符、32层括号，变量必须属于当前选择范围。无需输入F=，暂不解析LaTeX、Σm记号或整体上划线。

自主圈组首先要求格数为2的幂、不包含0、至少含实际1；再从所选输入提取固定比特，并枚举该模式的完整输入组合。所选集合必须与完整组合完全一致，才能构成合法立方体。这样允许四角、跨行边界和重叠，同时拒绝只有对角线的伪相邻组。

检查学生过程时，先核对覆盖，再把项数/文字数与精确求解结果比较。完整且真值等价的解可以导出，即使仍有冗余，导出内容也会明确标为“我的与或式”和“尚可优化”。系统只检查与或式的这项成本标准，不以表达式文字完全相同作为正确标准。

## 单变量线性回归

模型：ŷ=wx+b。训练损失定义为 L=Σ(ŷ−y)²/(2m)，所以显示的MSE等于2L。

- dw=Σ(ŷ−y)x/m；db=Σ(ŷ−y)/m。
- 使用相同旧w、b计算两项梯度，再同步更新，不能先更新w后用新w求db。
- 测试集从不参与求梯度或最小二乘参考。
- 最小二乘参考w=Σ(x−x̄)(y−ȳ)/Σ(x−x̄)²，b=ȳ−wx̄。
- 若所有x相等，参数不可唯一识别；显示w=0、b=ȳ这个最优解，并说明不唯一。

Hessian为 `[[mean(x²), mean(x)], [mean(x), 1]]`。其最大特征值λmax给出固定学习率的界0<η<2/λmax。数据没有满列秩时，此界仍可以保证损失向最小值收敛，但参数解未必唯一。界不等于实际最快学习率，也不保证有限几步达到精确最优。

样本限制2–200行，数值绝对值≤100000，支持科学计数法；参数和中间结果必须有限。实验最多2000步；若下一步参数绝对值>1e8或损失>1e12，该步不应用并提示调整学习率。这个数值保护不是发散证明。

模型图以观测数据决定坐标范围，所以发散后的直线可能移出画面；残差表与数值仍可复核。损失图纵轴是线性轴，长期迭代后局部微小下降可能看不清。

模型和参考直线按与绘图区边界的真实交点裁剪；超出范围的水平线不画，不分别截断两个预测端点来改变直线斜率。正负极大斜率的实际Canvas路径零点已独立核对，端点均在绘图区内；残差线裁到可见边界。

编辑输入与已应用实验分别保留。参数更新前图表继续展示已应用的值，并提示未应用；数据文本改变后先完整解析训练/测试与当前η，再一次性替换数据、归零w与b。失败不改变已应用实验。存在未应用输入时不能导出旧记录或存成回忆卡。临时输入可跨本页导航保留，刷新清除。轨迹逐步记录η、w、b与损失；第0步没有更新。

线性回归与批量梯度更新的基础参考：[Stanford CS229 Lecture Notes](https://cs229.stanford.edu/summer2023/cs229-notes1.pdf)。网页实验使用本项目自编合成数据，没有复用参考教材的数据集。

## 二分类指标

四格计数TP、FP、FN、TN各为0–10亿整数。Accuracy、Precision、Recall、F1与Specificity按未舍入计数求比；分母为0返回null，页面显示“未定义”。F1用2TP/(2TP+FP+FN)，避免先求Precision/Recall造成空分母传播。平衡准确率取正负两类Recall的平均，要求两种真实类别均存在。样本总数可到40亿，所有整数加法仍在JavaScript安全整数范围。

独立参考生成枚举每格0–4的624个非空组合，与scikit-learn 1.8.0核对；zero_division=NaN映射为null，缺失真实类别时平衡准确率按本工具约定置null。没有样本、非法计数另做边界验证。算例与公式来源见[分类指标实验单](分类指标实验单.md)。

## 复习计划

这是简单、可解释的个人复习安排，未声称实现SM-2或FSRS：

- 没想起来：层级归零，10分钟后复习。
- 想得吃力：层级降低一档，1天后复习。
- 独立回答：层级升一档，按1、3、7、14、30、60天递增。
- 能讲给别人：层级升两档，最多第6档。

每次间隔按评分时刻的实际毫秒时间计算，所以“1天后”指24小时后。日期看板按本机本地日期统计，不用UTC截断。用户若跨时区，统计日期会跟随设备。

基础自测答错时，为对应知识卡安排10分钟后的复习；答对自测不等于已经完成知识卡的主动回忆评分。

## 文本与备份

字数以`Array.from(text)`的Unicode码点数量统计；不含空白口径删除所有Unicode空白，另独立统计汉字和英文词数。组合emoji、组合附加符号可能含多个码点；不能承诺等同所有外部表单的计数。

备份校验版本、类型、日期、ID、长度、容量与枚举；拒绝原型保留名字。只复制定义过的字段，不执行文本。用户内容进入HTML前转义，文本显示使用安全内容；没有eval。

ID还拒绝Object.prototype的自有成员名称，避免`toString`等被错误当成已有进度。页面加载/导入再核对自建卡与基础卡ID无冲突、复习进度只引用存在的知识卡。课程名称不是固定枚举：已导入的非预设名称可筛选、编辑并按原值保存，选择框用显式value避免空格被浏览器折叠。

校验范围是已知存储结构。备份可以包含任何用户自填文字，校验不能证明经历真实，也不能自动确认所谓官方链接属于官方来源。

JSON文件读取上限64 MiB（67,108,864字节），与记录/字段上限协调：按每个字符串代码单元最多六字节转义、各结构全部取上限的保守格式化导出为60,581,391字节。页面还核对卡片引用，因此实际允许状态是此结构的子集。350张长中文卡的超过3 MiB备份已经通过浏览器导入、刷新与原值再导出。文件读取上限不扩大localStorage配额；保存失败时仍需导出当前页面内容。
