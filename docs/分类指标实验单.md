# 分类指标：从四格计数开始

打开工作台“AI小实验 → 指标辨析”。先定义正类，再读矩阵：行是真实类别，列是预测类别。本文计数为自编示例，不是手写数字模型的测试结果。

| 真实 / 预测 | 预测正类 | 预测负类 |
|---|---|---|
| 真实正类 | TP：命中 | FN：漏检 |
| 真实负类 | FP：误报 | TN：正确排除 |

设N=TP+FP+FN+TN。把指标理解成“先选出哪些样本作为分母，再数其中哪些成功”，能减少混淆。

| 指标 | 计算 | 回答的问题 |
|---|---|---|
| Accuracy | (TP+TN)/N | 所有样本中判对了多少？ |
| Precision | TP/(TP+FP) | 预测为正的样本中，真实正类占多少？ |
| Recall | TP/(TP+FN) | 真实正类中，找回多少？ |
| Specificity | TN/(TN+FP) | 真实负类中，排除多少？ |
| F1 | 2TP/(2TP+FP+FN) | 正类查准、查全的一种综合指标 |
| 平衡准确率 | (Recall+Specificity)/2 | 给两种真实类别相同权重后的平均找对比例 |

F1与平衡准确率仍不包含实际错误代价。Precision也不是单个样本的校准概率。公式与零除约定可核对[scikit-learn指标文档](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.precision_recall_fscore_support.html)与[模型评估文档](https://scikit-learn.org/stable/modules/model_evaluation.html)。

## 先独立计算，再看网页

总数1000，其中真实正类10个。方案A全部预测为负：TP=0、FP=0、FN=10、TN=990。

1. Accuracy是多少？
2. Recall是多少？
3. Precision的分母是多少？
4. 平衡准确率是多少？
5. 仅凭Accuracy能否说模型找到了目标类？

方案B：TP=8、FP=12、FN=2、TN=978。

1. 有多少样本被预测为正？
2. 独立算Precision、Recall、F1、Accuracy与平衡准确率。
3. 哪种错误减少了？哪种错误增加了？
4. 若漏检代价更高，仍缺哪些信息才能做真实决策？

在网页中修改四格，观察哪些分母改变。不要预先认为Precision与Recall一定同时上升。

## 核对答案

方案A：Accuracy=990/1000=99%；Recall=0/10=0%；Precision分母0，未定义；Specificity=990/990=100%；F1=0/10=0%；平衡准确率=(0%+100%)/2=50%。正类完全没找到。

方案B：预测正类20个；Precision=8/20=40%；Recall=8/10=80%；F1=16/30≈53.33%；Accuracy=986/1000=98.6%；Specificity=978/990≈98.79%；平衡准确率≈89.39%。漏检从10减至2，误报从0增至12；还需明确真实场景、采样方式、类别比例、错误代价和评估不确定性。

## 空分母必须写清约定

本工具以“未定义”显示分母为0的指标。F1直接用计数公式；方案A即使Precision未定义，F1仍有非零分母，因此等于0。四格全0时所有比例未定义。

平衡准确率采用两种真实类别Recall的算术平均，任一真实类别缺失时显示未定义。某些软件会只平均数据中出现的类别，或将零除替换为0、1、NaN；不能直接比较约定不同的报告。

网页计数限定每格0–10亿整数，使用双精度数；先计算未舍入的比值，再把百分比显示为两位小数。一次性测试枚举每格0–4的624个非空组合，与本机scikit-learn 1.8.0参考结果核对。参考生成采用zero_division=NaN，类别缺失的平衡准确率另按上述约定标记未定义。

最后导出指标记录，补写“正类定义、要回答的问题、错误代价、目前不能得出的结论”。存为回忆卡后，遮住答案再画一次四格表。
