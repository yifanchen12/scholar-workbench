# 用30分钟亲手理解线性回归

本实验使用“AI 小实验”页面的自编合成数据。不需要Python环境。建议先写预测，再点击按钮验证。

## 实验一：第一步到底在改什么？（8分钟）

选“有一点噪声的直线”，参数w=b=0，η=0.1。

在点x=1,y=3.1处，预测为0，残差ŷ−y为−3.1。在点x=−2,y=−3处，残差为+3。dw不是只看某个点，而是所有残差乘x后求平均；db是所有残差的平均。

操作前回答：

1. 当前直线处于哪里？
2. dw、db的符号会使w、b增大还是减小？
3. 为什么两个参数更新必须使用同一组旧梯度？

点击“走1步”，抄下w、b、L；再走20步，观察直线与最小二乘参考是否接近。

验收：不看页面答案，能写出L、dw、db及同步更新公式；能说明L与MSE相差因子2。

## 实验二：学习率不是越大越好（7分钟）

保留第一组数据，将学习率改为0.8，参数归零，再执行1步和20步。查看提示、损失轨迹与参数变化。页面会在数值过大前停止应用更新。

操作前预测：这组学习率是否超过页面显示的界？你预计损失是下降、振荡还是增长？

将η改为0.01、0.1分别重复，导出两份记录。

验收：能说明步长过大会使二次损失的梯度下降失稳；能区分“数值保护触发”和“已经证明发散”。

## 实验三：特征尺度会改变梯度（7分钟）

切换“同样规律，放大x50倍”。注意默认学习率一起变小了。

1. 原来的斜率约为2，现在应接近多少？
2. 把η改回0.1时，损失为什么可能快速增大？
3. 如果未来做标准化，均值和标准差应该在哪个集合上拟合？

验收：解释斜率近似缩小到原来的1/50；x²项使Hessian的尺度增长，相应稳定步长变小；预处理统计量只在训练集拟合。

## 实验四：最优训练拟合不保证测试表现（8分钟）

切换“一个离群点”，默认η=0.1。参数归零，先写预测：离群点会怎样拉动斜率与截距？再走20步。

比较最小二乘参考、训练L和测试MSE。训练与测试点仍都是演示数据。

验收：说明平方残差会放大离群点的影响；测试误差没有参与梯度；如果根据测试结果反复选择参数，就不能再把同一测试集当作一次独立的最终评估。

## 可留存的结果

下载实验报告，补上自己的解释。把没讲清的一个概念存为回忆卡，第二天遮住答案再解释一次。

修改w、b或η后，先点击“应用手动参数”或走一步。图表更新前会显示未应用提示，不能导出旧结果；编辑数据后先“载入数据并归零”。未应用输入可在本页切换标签/导航时保留，刷新会丢失。参数归零保留当前有效η；新数据载入也保留当前有效η，w与b归零。

如果中途换了学习率，报告的轨迹表会逐步保留实际η、w、b与损失。第0步没有更新，η列标为“—”。页面中的展示数值会舍入；轨迹表保留实际浮点参数，可按训练数据独立重算每次更新。
