# 一个能自己检查的数字分类实验

在工作台打开「AI 小实验 → 手写数字」。先用数据集样例观察模型，再清空画布写一个数字。识别失败时检查8×8预览、比较两种模型、试着平移输入。不要把高Softmax概率理解为“这次一定正确”。

## 数据与授权

使用scikit-learn内置的`load_digits()`：1797张8×8图片，每个像素为0–16，10个数字类别。这是digits数据，不是MNIST。原始数据出自E. Alpaydin与C. Kaynak于1998年发布的[UCI Optical Recognition of Handwritten Digits](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits)，DOI：10.24432/C50P49，授权为[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。

本项目对scikit-learn提供的1797张样本重新划分、训练模型，并选择留出集样本展示为像素数组。这些属于原数据的适配与衍生使用。来源、授权和适配说明同时保存在模型文件与可下载训练报告中。1797张样本与像素范围的依据见[scikit-learn官方数据文档](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html)。

## 训练与评估

预先固定随机种子2025，按类别分层做80/20随机划分：1437张训练侧样本、360张测试样本。所有像素直接除以固定常数16，没有从测试集拟合均值或方差。

| 模型 | 固定设置 | 测试结果 |
|---|---|---|
| 线性Softmax | LogisticRegression，C=2，lbfgs，最多2000次迭代；650个参数 | 351/360正确，97.5%，9个错误 |
| 小型神经网络 | 64→32 ReLU→10 Softmax，Adam，alpha=0.0005，batch=64，最多300轮；2410个参数 | 352/360正确，97.777…%，8个错误 |

两套配置各训练一次，没有根据测试成绩挑选模型或调参。神经网络启用早停，验证比例15%，验证样本只从1437张训练侧样本中划出。报告中的训练准确率是在整个训练侧集合上计算，因此包含早停验证样本，不能当成独立测试指标。

测试集未按书写者隔离。这次随机样本评估不能证明模型对全新书写者、鼠标画字或手机笔迹有同等准确率。97.5%和97.8%的差别只是此次360张样本中相差1张，不能据此得出神经网络普遍更好的结论。

展示的30张常规样例取自测试集，每类3张；8张误判是此次神经网络实际预测错误的全部样本。切换线性模型后，某些误判可能变为正确，也可能仍然错误。误判没有被伪造或挑成全部正确的演示。

## 浏览器怎样计算

模型权重保存为本地`digits-model.js`，推理由`StudyCore.classifyDigit()`执行。线性模型直接计算10类分数；神经网络先计算32维隐藏激活，经过ReLU，再计算10类分数。Softmax先减最大分数再取指数，避免指数溢出。所有运算都发生在当前浏览器，没有联网API或笔迹上传。

画布的预处理是本项目的简化方法：取非黑色区域的包围框，保持比例放入32×32黑色画布（最大宽24、高28），再按4×4块平均亮度得到8×8数组。它与原数据采集流程可能不同。数据集样例直接使用原始64维向量，不再重复预处理。平移功能直接移动8×8数组并裁掉边缘；这是用来观察位置变化，不保证识别改善。

权重热图只展示线性模型的某一类权重；神经网络隐藏单元没有被误称为具体数字类。空画布会显示待输入提示；下载的空输入报告仍包含数学前向结果，并明确标注`blankInput`，不把它当成已识别的数字。

## 复现与验证

普通使用只需浏览器，已附模型权重，无需Python或安装机器学习包。重新训练需要Python、NumPy、scikit-learn；本次使用scikit-learn 1.8.0，执行：

```powershell
python scripts/train-digits.py
node tests/digits.test.cjs
node tests/digits-browser.test.cjs
```

训练脚本会覆盖模型、训练报告与100张独立Python预测参考。不同库版本或数学运行库可能产生略有差异的权重，保留版本与设置后再比较。

浏览器推理与Python的100张测试样本、两种模型共200次前向计算对照：最大概率误差2.082×10⁻¹⁰（权重保留10位小数），预测类别全部一致。真实浏览器另验证画笔预处理、键盘像素操作、平移、实际误判、模型切换、JSON下载、6种宽度和直接文件模式。报告保留混淆矩阵、对数损失、迭代次数和完整配置，便于核对。
