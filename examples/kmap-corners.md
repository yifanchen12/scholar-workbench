# 卡诺图化简

变量顺序：ABCD（左侧为高位）

F = Σm(0, 2, 8, 10)

| AB \ CD | 00 | 01 | 11 | 10 |
|---|---:|---:|---:|---:|
| 00 | 1① | 0 | 0 | 1① |
| 01 | 0 | 0 | 0 | 0 |
| 11 | 0 | 0 | 0 | 0 |
| 10 | 1① | 0 | 0 | 1① |

## 分组

①：(m0, m2, m8, m10) → B'·D'

## 最简与或式

F = B'·D'

$$F = \overline{B}\overline{D}$$

真值验证：通过（无关项不参与一致性要求）。
优化顺序：先最少乘积项，再最少文字数；等价最简式可能不唯一。
编号标记表示分组，重复标记表示该格参与多个组。
